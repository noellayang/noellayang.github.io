Lighting Up Canada Review Backend

view the map

About

Google Sheets and Apps Script review backend for PBCM's public initiative-tracking map, with AI-assisted research and mandatory human approval before publication.

Tools

Google Apps Script, Google Sheets, JavaScript, Leaflet, GitHub Pages, prompt design

Project

PBCM wanted a national map of documented plant-based initiatives across Canadian institutions. I built the research, review, and publishing workflow behind it so the database could grow without removing human verification.

Public map

I first built the public map in Leaflet and hosted it on GitHub Pages. The early version included search, category filtering, and 17 institutions; the dataset reached 62 by the second week as the review workflow took shape.

Review workflow

The Google Sheet is the source of truth, with an Apps Script web app for review. Each record is kept in one of three states:

  • Review Queue: new or flagged records, everything starts here
  • Published Records: approved, exported to the live map
  • Rejected Archive: rejected, kept for history instead of deleted

Reviewers can Proceed, Hold, or Reject a record. Only Proceed sets the approval fields required for export. The research prompts cannot set those fields, so AI can suggest records and sources but cannot publish them.

Research workflow

I wrote separate prompts for discovery and later verification. Discovery checks new candidates against existing names and aliases, requires a source for each claim, separates announcement dates from implementation dates, and routes uncertain cases for review instead of guessing. The audit workflow checks published records for stale claims, changed sources, and broken links while preserving source history.

Publishing

Approved records are exported directly to institutions.json for the public map, so staff do not have to edit JSON by hand or redeploy the Apps Script after each review decision.

Handoff

By the end of the internship, the review backend was live and the database had grown beyond the initial 62 records. I documented the full workflow, trained PBCM staff to operate it independently, and presented the system at a board meeting.
